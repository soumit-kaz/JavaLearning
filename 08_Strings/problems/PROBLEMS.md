# 08 - Strings: Problems

Each solution runs its own tests and prints one PASS or FAIL line per test.

## P01 - Count Vowels (Easy)
Count the vowels (a, e, i, o, u, in any case) in a string.
Example: `"hello"` -> `2`
Solution: [M08P01_CountVowels.java](P01_CountVowels/M08P01_CountVowels.java)

## P02 - Valid Palindrome (Easy)
Does a phrase read the same both ways, ignoring case and anything that is not a letter or digit?
Example: `"A man, a plan, a canal: Panama"` -> `true`
Solution: [M08P02_Palindrome.java](P02_Palindrome/M08P02_Palindrome.java)

## P03 - Valid Anagram (Easy)
Do two lowercase words use exactly the same letters the same number of times?
Example: `"listen", "silent"` -> `true`
Solution: [M08P03_Anagram.java](P03_Anagram/M08P03_Anagram.java)

## P04 - Reverse Words (Easy)
Reverse the order of the words. Use single spaces between words and none at the ends.
Example: `"  hello world  "` -> `"world hello"`
Solution: [M08P04_ReverseWords.java](P04_ReverseWords/M08P04_ReverseWords.java)

## P05 - Capitalize Words (Easy)
Make the first letter of every word upper case and the rest lower case. Keep all spaces as they are.
Example: `"hELLO wORLD"` -> `"Hello World"`
Solution: [M08P05_CapitalizeWords.java](P05_CapitalizeWords/M08P05_CapitalizeWords.java)

## P06 - String Compression (Medium)
Replace each run of one letter with the letter and the run length. If that is not shorter, keep the original.
Example: `"aabcccccaaa"` -> `"a2b1c5a3"`, `"aabb"` -> `"aabb"`
Solution: [M08P06_StringCompression.java](P06_StringCompression/M08P06_StringCompression.java)

## P07 - Longest Common Prefix (Medium)
Find the longest text that every word in an array starts with.
Example: `["flower", "flow", "flight"]` -> `"fl"`
Solution: [M08P07_LongestCommonPrefix.java](P07_LongestCommonPrefix/M08P07_LongestCommonPrefix.java)

## P08 - Roman to Integer (Medium)
Convert a Roman numeral (I, V, X, L, C, D, M) from 1 to 3999 into an int. A smaller symbol before a bigger one is subtracted.
Example: `"MCMXCIV"` -> `1994`
Solution: [M08P08_RomanToInteger.java](P08_RomanToInteger/M08P08_RomanToInteger.java)
