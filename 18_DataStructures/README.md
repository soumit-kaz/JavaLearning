# 18 - Data Structures and Algorithms

Build the classic data structures and algorithms from scratch. Work through the subfolders in order.

| # | Subfolder | What you build | Lessons | Problems |
|---|-----------|----------------|---------|----------|
| 1 | [01_Linear](01_Linear/README.md) | dynamic array, linked lists, stack, queue, monotonic stack/queue | 6 | [6](01_Linear/problems/PROBLEMS.md) |
| 2 | [02_Hashing](02_Hashing/README.md) | hash map (chaining, open addressing), hash set | 3 | [4](02_Hashing/problems/PROBLEMS.md) |
| 3 | [03_Trees](03_Trees/README.md) | traversals, BST, AVL tree, trie, segment and Fenwick trees | 6 | [6](03_Trees/problems/PROBLEMS.md) |
| 4 | [04_Heaps](04_Heaps/README.md) | binary heap, heap sort, priority queue, running median | 3 | [5](04_Heaps/problems/PROBLEMS.md) |
| 5 | [05_Graphs](05_Graphs/README.md) | BFS/DFS, topological sort, shortest paths, MST, union-find | 6 | [6](05_Graphs/problems/PROBLEMS.md) |
| 6 | [06_Advanced](06_Advanced/README.md) | LRU cache, skip list, Bloom filter, sparse table | 4 | [5](06_Advanced/problems/PROBLEMS.md) |
| 7 | [07_Algorithms](07_Algorithms/README.md) | sorting, binary search, two pointers, sliding window, backtracking, DP | 15 | [6](07_Algorithms/problems/PROBLEMS.md) |

All problems: [PROBLEMS.md](PROBLEMS.md)

## How to run

```
cd 18_DataStructures/01_Linear
java M1801L01_DynamicArray.java
```

A lesson prints a short demo and then `OK`. A problem solution prints one `PASS` line per test.
